# 0006 — No AI tool is credited, without exception

**Status:** accepted · **Date:** 2026-10-03

## Context

Every commit, file and historical record in this repository is the work of one
person. A commit that credits a tool is a claim about authorship that is false
here, and it is the kind of claim a reader can verify in two clicks.

## Decision

No AI tool is credited in any commit message, any tracked file, or the history.
Enforced in three independent places, so removing one does not remove the rule:

1. **A `commit-msg` hook** blocks a trailer naming anything but the owner. It
   was proven to block before it was trusted: a probe commit with a tool trailer
   exits 1, a clean commit exits 0.
2. **`pnpm verify:attribution`** scans the working tree, every commit message on
   every ref, and the distinct author names in history.
3. **CI runs it with `fetch-depth: 0`**, because a shallow clone would let the
   gate report PASS while proving nothing about history.

## Where the rule stops, and why

The gate does **not** flag the words "claude", "openai" or "AI" in the code,
and it does not flag a robot emoji in the product's own pipeline diagram.

This is not a loophole; it is the point. This product classifies failures with
a language model. Removing every mention of that would misrepresent what the
software does, and an inaccurate project is worse than an attributed one. The
patterns are therefore anchored to **attribution shapes** — a banner at the top
of a file, a trailer, "generated by", a robot emoji standing alone on a line —
rather than to the bare words.

A guard that fires on legitimate content is a guard that gets switched off, and
a switched-off guard protects nothing.

## The distinction this project draws

|                |                                                                                  |
| -------------- | -------------------------------------------------------------------------------- |
| **Authorship** | Sole. No co-author trailers, no tool stamps, anywhere. Enforced.                 |
| **Capability** | The software uses a model, and says so plainly. Not attribution, and not hidden. |
